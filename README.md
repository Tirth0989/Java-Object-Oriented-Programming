# Java Object-Oriented Programming Portfolio

A collection of ten Java programming exercises completed for **COMP601**. The project progresses from formatted output and input validation to classes, inheritance, polymorphism, recursion, collections, and file-based applications.

## Topics demonstrated

- Console input and formatted output
- Arithmetic calculations and numeric formatting
- Input validation with loops and conditional logic
- Arrays, lists, and nested iteration
- Classes, objects, constructors, getters, and setters
- Encapsulation using private fields
- Inheritance and superclass constructors
- Method overriding and polymorphism
- Recursive programming
- File input/output and object persistence
- Random selection and simple interactive applications

## Assignment tasks

| Task | Exercise | Main concepts |
|---:|---|---|
| 1 | Formatted output | Escape sequences and `printf` column formatting |
| 2 | Circle calculations | User input, arithmetic, `Math.PI`, and decimal formatting |
| 3 | Score validation | Loops, ranges, conditional grading, and validation |
| 4 | Overlapping colours | String splitting, arrays, lists, and nested loops |
| 5 | Musical notes | Classes, instances, encapsulation, methods, and aggregation |
| 6 | Vegetable statistics | Inheritance, subclasses, constructors, and collection processing |
| 7 | Shapes and rectangles | Polymorphism, overriding, arrays of objects, and perimeter comparison |
| 8 | Bag capacity | Objects, lists, recursion, and a recursive base case |
| 9 | Country guessing game | File I/O, random selection, objects, and user interaction |
| 10 | Audiobook processing | Inheritance, file parsing, filtering, counting, and randomized lists |

## Running the code

1. Install the Java Development Kit required by the course.
2. Create a Java project in IntelliJ IDEA, Eclipse, NetBeans, or another Java IDE.
3. Copy one task at a time from `COMP601_Java_Solutions.txt`.
4. Place each public class in a matching `.java` file and retain its package declaration.
5. Add any required text data files to the correct `src` package folder.
6. Compile and run that task's main class.

Some exercises use the modern Java syntax provided by the course, including `import module java.base`, `java.lang.IO`, and instance `main` methods. Use the course-configured JDK. With an older JDK, convert these sections to a standard `public static void main(String[] args)` method with `Scanner` and `System.out`.
